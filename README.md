# FL Lingo

FL Lingo is a Windows desktop tool for relocalizing Freelancer mod installations. It compares a modded install with a clean reference install, restores safe translations automatically, prepares remaining mod text for manual or external translation, and writes completed text back into the resource DLLs with backups.

## What FL Lingo Does

1. Scans a modded Freelancer installation and a clean reference installation side by side.
2. Matches resource entries that can be safely reused.
3. Highlights mod-only text that still needs translation.
4. Writes finished translations back into the selected mod DLLs with backups.

FL Lingo supports `RT_STRING` string tables and `RT_HTML` infocards across resource DLLs referenced by `freelancer.ini`.
